# [RustCrypto]: NIST DRBGs

Pure Rust implementation of [NIST SP 800-90A Rev. 1] deterministic random bit generators.

## ⚠️ Security Warning

This crate has never received an independent third party audit for security and
correctness.

USE AT YOUR OWN RISK!

## Minimum Supported Rust Version

Rust **1.85.1** or higher.

Minimum supported Rust version can be changed in the future, but it will be
done with a minor version bump.
